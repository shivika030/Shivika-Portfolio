## Featured Projects

### SkinAI: AI-Based Skin Condition Classification

A deep learning application that classifies skin conditions from images.

- Fine-tuned ResNet18 model for image classification
- Image preprocessing and inference pipeline built with PyTorch
- REST APIs developed with FastAPI
- Frontend built with React and TypeScript
- Containerized deployment using Docker

**Tech stack:** Python, PyTorch, ResNet18, FastAPI, React, TypeScript, Docker

**Repository:** [github.com/shivika030/SKIN-AI](https://github.com/shivika030/SKIN-AI)

### OneSelf: Women's Wellness Application

A mobile application for cycle tracking and personalized wellness guidance.

- Cycle tracking and symptom logging
- Calendar-based tracking with phase-based predictions
- Personalized food and activity suggestions
- AI-powered wellness assistant using Groq LLM
- JWT authentication and MongoDB integration

**Tech stack:** React Native, TypeScript, FastAPI, MongoDB, JWT, Groq LLM

**Repository:** [github.com/shivika030/Oneself](https://github.com/shivika030/Oneself)
